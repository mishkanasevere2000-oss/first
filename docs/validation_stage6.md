# Проверка этапа 6 — 0.12.0

Схема SQLite 2; новые зависимости не потребовались. Облачная проверка:
`python -m pytest -q` — 357 passed, включая 29 сценариев пользовательского разбора.
Проверка пользователем на Windows ещё предстоит.

| Требование | Проверка |
| --- | --- |
| A7: ручное решение сохраняется и выше правил | Повторное чтение базы, история из двух связанных решений, пересчёт с конфликтующим правилом |
| A8: решение не создаёт правило | Реальный диалог сохранения и отказ от отдельного мастера; таблица rules остаётся пустой |
| A8: отдельная активация правила | Формальный просмотр, отмена без записи, отдельное ДА; версии и отключение без изменения истории |
| A9: конфликты требуют разбора | Сценарии движка сохранены; очередь содержит неизвестные типы и противоречивые связи |
| A10: известный расход без категории учитывается | В итогах сумма 10000 копеек, review_required; никакой автоматической категории «Прочее» |
| Безопасность изменений | Устаревшее состояние отклоняется; смена данных во время backup правила отклоняется; сбой аудита откатывает ручное решение целиком |
| Поиск и интерфейс | Пагинация, фильтры, настоящий проход главного меню → поиск → карточка → ручное решение → выход; EOF; мастер условий |
| Личные справочники | Нет предустановленных категорий; подтверждение своего счёта; запрет дубликатов, неверных родителей и недействительных ссылок |
| Связи | Подтверждение/отклонение своего перевода, несколько возвратов, запрет переплаты/пересечения/противоречия ручному решению |

Вне репозитория создана временная база из 12 предоставленных PDF, каждый загружен
дважды: 564 операции, 24 SUCCESS, без дублей. Сохранены 564 неопределённых решения,
как в пользовательской версии 0.11.0. На этой базе проверены очередь разбора,
создание тестовой категории, ручное решение, просмотр и активация тестового
правила, пересчёт истории с сохранением ручного приоритета. Все исходные поля
operations совпали с состоянием до разбора. Временные данные удалены; в Git
публикуются только код, документация и вымышленные тесты.

Проверка Excel и независимого QA относится к этапу 7; приёмка всего MVP не заявляется.
