# Этап 6 — пользовательские решения и правила

Основание: этап 6 плана v1.0, разделы 8, 9, 12.3 ТЗ v1.1 MVP и архитектура v1.0.
Версия 0.12.0, схема 2. Область приёмки: пользовательская часть A7–A10.

Реализованы разбор неопределённых, поиск по описанию/MCC/ID и фильтры периода,
банка и счёта; ручные решения с историей; отдельный мастер правила с формальным
просмотром условий и отдельной активацией; просмотр версий и отключение правил.
Расход без категории учитывается в виртуальных «Неклассифицированных расходах».

Дополнительно даны консольное создание личных категорий/подкатегорий,
подтверждение собственных счетов из загруженных операций и подтверждение/отклонение
связей переводов/возвратов/цепочек. Категории, счета и правила не предустановлены.
Правила для будущего не пересчитывают прошлые решения; пункт 6 → 3 делает это
отдельно с просмотром и backup, сохраняя приоритет ручных решений.

По просьбе пользователя вывод разделён пустыми строками и разделителями:
главное меню, карточка операции, результат действия, очередной PDF.

Слои: database/review.py — SQLite; processing/review.py — проверки и команды;
ui/review.py — диалоги. Изменение исходных банковских фактов не допускается.
Excel/независимый QA остаются этапом 7, эксплуатационная автоматизация — этапом 8.
Проверка на Windows пользователем ещё предстоит.
