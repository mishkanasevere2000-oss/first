Исходные ТЗ v1.1 MVP, архитектура v1.0 и план v1.0 повторно получены и изучены.
Реализация: 0.11.0, схема SQLite остаётся 2. Проверка на Windows пользователем

## Зафиксированные требования исходных документов

- Банковские факты неизменны; финансовые решения хранятся отдельно.
- Приоритет: последнее ручное решение, подтверждённые связи, сохранённое решение
  (кроме явного пересчёта истории), автоматические правила, неопределённость.
- Технические перемещения исключаются только при достаточных подтверждениях.
  Совпадение даты и суммы не подтверждает собственный перевод.
- Полный и частичный подтверждённый возврат уменьшают расходы, а не создают доход.
- Правила — пользовательские данные с версией, приоритетом и датой активации.
  Нет процентов уверенности и встроенных личных категорий/банковских догадок.
  Равноприоритетные противоречащие результаты требуют проверки.
- Изменение правил не переписывает историю. Пересчёт показывает период, число
  изменений и влияние на суммы; после подтверждения создаётся проверенный backup.
  Ручные решения защищены, сохранение целиком атомарно.
- Известные расходы без категории включаются в виртуальную группу
  «Неклассифицированные расходы». Неизвестный финансовый тип делает итог неполным.
- Период определяется датой совершения; исходная дата проводки сохраняется.

Эти требования соответствуют области сценариев A4–A9, A15–A17 и A22–A23.
Это проверка механизмов этапа 5, а не приёмка всех сценариев готового MVP.
