# Кредитная карта ВТБ — текстовый PDF, программа 0.7.0

Третья часть этапа 4: конкретный формат карточной выписки ВТБ с «Контракт»,
«СКС», «Информация о балансе карты», «Операции по карте», кредитными отчётами
и названием банка в конце документа. Определение по содержимому, не имени.

## Что сохраняется и проверяется

- Счёт операции — СКС. «Номер счета для зачислений» не используется вместо
  клиентского счёта; маскированная карта также не является номером счёта.
- Сохраняются дата совершения, дата обработки, время с секундами на отдельной
  строке, полное описание с переносами, сумма в целых копейках и направление.
  Отрицательная сумма операции — OUT, положительная — IN. Вторая колонка
  содержит абсолютную сумму в валюте карты и должна совпадать по модулю.
- Десятичная точка и одна/две цифры после неё читаются без float.
- Поддерживаются только RUB и нулевая комиссия как по операциям, так и по
  итогам. Валютная конвертация и ненулевая комиссия явно запрещают импорт:
  их разбор требует отдельного образца и модели сохранения этих сведений.
- Дата обработки должна входить в период. Дата совершения вне периода
  сохраняется с предупреждением. Время сохраняется в operation_time_local,
  operation_time_zone=NULL: явного часового пояса в документе нет.
- Остатков после отдельных операций, MCC и явного уникального ID нет: NULL.
  Коды в описании не объявляются ID или кодом авторизации. Аналитические
  категории не назначаются. Кредитный лимит и задолженность из служебных
  отчётов не превращаются в дополнительные операции.
- Итоги строк обязательно совпадают с поступлениями и расходными операциями,
  начальный баланс + обороты — с конечным балансом. Отрицательные балансы
  допустимы, исходные значения сохраняются. Несходящиеся суммы запрещают запись.
- Проверяются заголовки таблицы и последовательность номеров всех страниц,
  включая кредитные отчёты; неполные/непонятные строки и отсутствие времени
  останавливают запись. Сканы и другие варианты оформления не принимаются.

## Повторы и совместимость

Используется общий накопительный импорт, история попыток и проверенный архив
archive/statements/ГОД/vtb/SHA256.pdf. Дата, время, сумма и описание участвуют
в сопоставлении по признакам; одинаковые реальные покупки сохраняются по
количеству вхождений. Для ВТБ время берётся из operation_time_local. Прежний
признак operation_time_moscow Сбера и хеши его операций не меняются; Ozon
по-прежнему сопоставляется по номеру банковского документа. Схема остаётся 2.

При обновлении в отдельную папку сначала перенести прежнюю базу командой
copy и папку archive целиком, сохранив прежнюю установку; команды в README.
Проверки check/info должны подтвердить исходные данные до нового импорта.
Ввод PDF обычный: копия в input → BAT → пункт 1 → просмотр → ДА.
