# Ozon Банк — текстовый PDF, программа 0.5.0

Это первая часть этапа 4: один дополнительный банк, не все возможные выписки.
Поддерживается рублёвая «Справка о движении средств» ООО «ОЗОН Банк» с колонками
«Дата операции», «Документ», «Назначение платежа», двумя суммами в рублях,
начальным/конечным остатком и итогами зачислений/списаний. Сканы, другие валюты,
иные варианты оформления автоматически не принимаются.

## Факты и контроль

- Дата, время с секундами, номер документа, полное назначение платежа,
  абсолютная сумма в копейках и направление IN/OUT сохраняются как факты.
- Перенос номера документа внутри его колонки объединяется; продолжения
  назначения сохраняются как исходные строки и нормализованное описание.
- Номер документа используется как банковский ID в пределах банка и счёта.
  Повтор номера в файле или противоречие известному ID останавливают запись.
  Это проверено на предоставленной выписке и вымышленных перекрывающихся PDF;
  поведение других вариантов нумерации Ozon ещё не подтверждено.
- Дата обработки, MCC и остаток после каждой операции отсутствуют: NULL.
  Часовой пояс в документе не указан: время сохраняется в source_data как
  operation_time_local, operation_time_zone=NULL; оно не объявляется московским.
- Суммы обеих валютных колонок должны совпасть; все суммы строк сверяются
  с отдельными итогами банка, начальный остаток + обороты — с конечным.
- Непонятная строка, повреждённая дата/сумма, пропущенная страница, повторный
  номер документа или несходящиеся итоги запрещают финансовую запись.
- Категории и аналитические доходы/расходы не определяются. Текст «Перевод
  собственных средств» сам по себе не является пользовательским решением.

## Импорт и обновление

Схема остаётся 2, существующие записи не меняются. В новой папке сначала
перенести прежнюю базу через database copy и папку archive целиком, как в README.
После установки: pytest, database init/check/info. Не создавать пустую базу
вместо существующей. Старую установку сохранить.

Обычный путь: скопировать PDF в input → BAT → пункт 1 → предварительный просмотр
→ ДА. Повторы определяются по файлу и документам. Архив:
archive/statements/ГОД/ozonbank/SHA256.pdf; Сбер сохраняет папку sberbank.
Проверка и восстановление архивов, журнал попыток и защита исходника остаются
общими для обоих банков. Одновременно работать одним экземпляром программы.

## Проверка разработчиком

- Полный набор: 162 passed (Linux), зависимости совместимы (pip check).
- 20 новых тестов: реальное извлечение двухстраничного вымышленного PDF,
  перенос номера, неверные поля/страницы/итоги, NULL отсутствующих фактов,
  отдельный часовой пояс, смешанный импорт со Сбером, повтор по новому хешу,
  короткая → полная выписка, конфликт ID с откатом и сохранением исходника.
- Настоящий пользовательский PDF проверяется только вне Git: 108 операций,
  52 зачисления и 56 списаний, по 676 108,50 ₽; остатки 0 → 0.
- Независимое извлечение Poppler сверено с pypdf по каждой из 108 строк:
  дата, время, номер документа, описание, сумма и направление совпали.
- Проверка реальных файлов во временной базе: две выписки Сбера дают 143
  операции, Ozon добавляет 108, итог 251; повтор Ozon даёт 0 новых / 108 известных.
- Настоящие PDF, тексты, реквизиты и временные базы не публикуются.

Windows-проверка 0.5.0 пользователем ещё предстоит. Это не финальная приёмка
этапа 4: другие банки и форматы будут добавляться по отдельным образцам.
