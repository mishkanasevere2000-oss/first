# Россельхозбанк — карточный PDF, программа 0.8.0

Четвёртая часть этапа 4: конкретная рублёвая «Выписка по карточному счёту»
с маркером дополнительного офиса №3349/ и показанным расположением колонок.
Распознаётся по содержимому и структуре, не имени файла. Сканы, другие формы,
валюты, валютная конвертация и ненулевые комиссии не поддерживаются.

## Существенное ограничение сверки

В этом формате нет отдельных итогов пополнений/списаний и печатной нумерации
страниц. Входящий остаток + суммы строк IN − суммы строк OUT должны дать
исходящий остаток; иначе запись запрещена. Но исчезновение сбалансированной
пары или страницы математически может остаться незаметным. Автоматического
подтверждения полноты по независимым итогам и нумерации здесь нет.

Поэтому приложение показывает «Пополнения/списания по строкам», не пишет
«суммы совпадают с итогами банка» и предупреждает о пределах проверки
до подтверждения и после импорта. В исходных метаданных сохраняется
bank_turnover_totals_present=false. Вычисленные обороты не выдаются за
независимые банковские итоги. Это проверено отдельным тестом с намеренно
удалённой сбалансированной страницей. Полноту такой выписки нужно проверять
по исходному документу; для предоставленного образца все строки независимо
сверены разработчиком двумя средствами извлечения текста.

## Сохранение банковских фактов

- Читается номер счёта из рублёвой шапки; сохраняются обе даты, время HH:MM,
  полное описание с переносами, сумма в копейках и направление по знаку.
- Запись времени 00:00 сохраняется буквально. Время из текста назначения
  перевода не подменяет время отдельной колонки; часовой пояс не угадывается.
- Формат суммы: точка для копеек, запятая для тысяч; без float. Сумма в валюте
  счёта должна совпасть со знаковой суммой операции. Комиссия должна быть нулевой.
- Маска карты из отдельной колонки сохраняется в source_data.card_number_mask,
  не добавляется в описание и участвует в признаках идентичности, если есть.
- Дата обработки должна быть в периоде; даты совершения вне него сохраняются
  отдельно с предупреждением. Остатка после каждой операции и MCC нет: NULL.
- SBP ID, даты и коды внутри описаний сохраняются как текст; они не объявляются
  универсальным уникальным ID всех строк. Используется сопоставление по
  признакам и количеству вхождений: одинаковые погашения не схлопываются.
- Предоставление кредита, погашение и возвраты остаются банковскими фактами,
  не получают автоматически аналитические категории, доход или расход.
- Неизвестная строка, неверное время, дата, сумма или маска останавливают запись.

## Совместимость

SQLite-схема остаётся 2. Прежние поля без маски карты сохраняют прежние хеши.
Метаданные дополнены признаком источника оборотов, миграция не требуется.
Архив: archive/statements/ГОД/rshb/SHA256.pdf. История попыток, защита повторов,
проверка архивной копии и восстановление общие с другими форматами.

Обновление в отдельную папку: сначала copy существующей базы и перенос archive,
затем check/info. Прежнюю установку сохранить; команды в README. Обычный импорт:
копия PDF в input → BAT → пункт 1 → просмотр предупреждений → ДА.
